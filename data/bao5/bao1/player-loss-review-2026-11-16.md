球员实际分通过 BAO5 API `/api/nba/player-log?id=…&recent=120` 拉取。之前的定时流程因周刷新日期判断跳过请求，并非接口不提供历史赛果。本地强制补拉成功：529/529 名活跃球员成功、4,428 场本赛季日志，最新比赛日为 2026-11-15。随后使用赛果回填模式把球员实际分写回预测快照；该模式跳过阵容计算和提交。11 月 14—16 日预测快照原本在本地空缺，已从远端原始快照恢复，再匹配实际赛果。

预测日与球员日志日期可能跨美东午夜；回填现按已结束赛程的比赛 ID 和美东比赛日匹配。确认同队对手比赛结束而球员没有个人 box score 的记录按实际 0 分保存。

## 参数决定与逐球员二次反事实

上一轮检查显示，单纯按训练集 Bias 统一加分会让留出 MAE 从 8.550 变为 8.596（变差）；对位权重减半、移除或加倍，留出 MAE 仍在 8.549–8.561 之间。因此没有改 C/PF 对位权重，也没有做全局偏差平移。

随后按用户指出的逐球员目标重新检查保存的分项。现有 0.896 常规赛校准系数来自“本人所选五人阵容”总分，只在少数完整阵容样本上拟合，却被乘到全体球员；对所有球员都向前场/后场中位数收缩一个完整先验场次，也会压低高均分球员。基于当时保存的预测特征做时间顺序反事实：训练期仍用 11-09—11-12，留出仍用 11-13—11-15。

| 留出方案 | MAE | RMSE | Bias（实际−预测） |
|---|---:|---:|---:|
| 原模型 | 8.550 | 11.314 | +2.822 |
| 仅取消阵容总分校准 | 8.459 | 11.027 | +1.820 |
| 取消阵容校准，并把常规赛位置先验从 1 场降为 0.25 场 | **8.298** | **10.939** | **+1.795** |

组合方案训练期 MAE/RMSE 为 7.468/9.847，较原模型 7.454/9.821 仅分别变化 +0.014/+0.026；全周 MAE/RMSE 从 7.850/10.385 降至 7.768/10.255。留出期按同一批已知主位置样本比较：

|---|---:|---:|
| C | 7.902 / 10.800 / +2.593 | 7.654 / 10.441 / +1.558 |
| PF | 8.672 / 10.972 / +2.578 | 8.478 / 10.716 / +1.557 |
| PG | 10.016 / 13.386 / +5.547 | 9.406 / 12.602 / +4.262 |
| SF | 8.833 / 11.280 / +1.338 | 8.745 / 11.110 / +0.379 |
| SG | 7.558 / 10.195 / +2.562 | 7.394 / 9.906 / +1.682 |

五个位置的留出 MAE/RMSE 均下降。按这个结果采用组合修正，保留原来的位置对位权重。

约基奇作为高能量球员的例子：本地下一场原预测为 52.1 分；最近六场为 61.8、67.5、51.6、63.7、57.2、55.6，均值 59.6，只有 1 场低于 52。取消阵容校准并减轻先验收缩后，按已保存的模型信号重算约 59.6 分，与这六场均值接近；最终分数仍会随当天赔率、历史对阵和选人反馈更新。

## 出场时间与替补机会迭代

旧代码只有在球员自己带有伤病状态时才检查替补机会；且缺阵报告常不含球队/位置字段，导致健康替补拿不到同队缺阵分钟。现已改成从完整球员名单补出缺阵球员的球队、位置分布和本季分钟，再按位置重合与轮换分钟把预计空出的时间分配给最多 5 名可用替补。单名球员新增预计时间最多 8 分钟，预计分增幅最多 35%；本人伤病概率仍单独折算。每天保存预计分钟和新增分钟，便于下一轮逐球员回测。

本地前端刷新后的实际输出：约基奇 59.6 分；勇士名单显示库里、穆迪、布兰登·威廉姆斯缺阵时，梅尔顿预计 31 分钟、28.0 分，佩顿二世预计 14.5 分钟、10.4 分。离线预览因未带入前五选人信号，约基奇显示 58.5 分。该分钟分配是刚加入的结构修正，还没有相应历史预测快照可做诚实的留出验证；后续工作日复盘将重点校准它，若新样本表现变差可直接回退。未提交 BAO5 阵容。

## 刷新链路与本地改动

远端工作流按北京时间每天 19:00 刷新球员位置；11 月 9—16 日均有位置档案，最新包含 469 名球员。模型数据提交链路仍在更新，但位置覆盖仍低于此前对照的 521 人。

逐场球员日志的周刷新跳过问题已在本地修正：改为检查最近一次周日 19:00 刷新窗口，因此延迟到周一运行仍会补拉。赛果回填也改为使用已结束赛程的比赛 ID 和美东比赛日匹配，避免跨日时把已出场球员误记为 0。两项代码改动和补齐后的数据目前都只在本地，未提交或推送；未提交 BAO5 阵容。

## 结论

API 能补取逐球员历史实际分，预测记录也已存在；原缺口来自周刷新跳过和本地快照落后。现已补齐本地 11 月 9—15 日的 1,315 条预测与实际值。当前小迭代移除了不适用于单球员的阵容总分校准，降低成熟球员的位置中位数收缩，并让已确认缺阵队友的轮换分钟进入替补预计分。

NBA 模型复盘自动任务已改为北京时间周一至周五 19:00 执行。代码和报告仅留在本地，未推送代码，也未提交 BAO5 阵容。
