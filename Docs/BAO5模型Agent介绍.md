# BAO5 每日一阵模型介绍

## 这个 Agent 做什么

BAO5 每日一阵 Agent 面向「每日一阵」玩法：根据指定比赛日的赛程和球员数据，给每位候选球员估分，再从中挑出满足游戏规则的五人阵容。它的目标是提高阵容的预期 Fantasy 得分，同时把数据不确定性和伤病风险明确纳入判断。

Agent 负责生成建议阵容和解释选人依据。提交到 BAO5 是单独的执行步骤，会再次校验球员、阵型、能量和比赛锁定时间，并在提交后回读确认。

## 行为模式

### 偏低风险

默认模式。近期状态、历史对阵、对位、赔率和前五选人等信号采用较轻的修正幅度；对伤病和不确定出场状态相对谨慎。基础技术统计仍是主要评分依据。

### 高风险

提高近期状态、历史对阵、对位、赔率、替补机会和前五选人反馈的影响。它更愿意根据短期信号改变球员排序，但这些信号样本有限，预测波动也会更大。

### 自定义

用户可以调整五项信号占比。页面拖动任一比例时，会按其余项目当前比例重新分配剩余部分，并把总和维持在 100%。提交给模型后，各项占比会映射到对应信号的可用修正范围。伤病惩罚、替补机会和阶段折扣仍按各自规则独立处理。

## 决策思路

### 1. 确定当日可选范围

读取 BAO5 球员库与赛程，按比赛日筛出当天参赛球队的有效球员。已结束比赛不纳入未来预测；预测窗口展示接下来最多七个赛程日。

### 2. 估算球员基础分

按 BAO5 计分公式计算 Fantasy 得分：

```text
得分 + 1.2 × 篮板 + 1.5 × 助攻 + 3 × 抢断 + 3 × 盖帽 − 失误
```

新赛季样本较少时，会按已出场场数降低统计可信度，避免少量表现直接主导预测。BAO5 没有提供的近期逐场数据不会被伪造；缺少近期或对阵样本时，相应信号回落到中性处理。

### 3. 加入比赛与球员状态信号

- **近期状态**：有近期平均分时，与基础分按模式权重混合。
- **历史对阵**：参考球员对该对手的历史表现相对其自身总体表现的差异；样本缺失时不做调整。这不是 BAO5 同口径的完整历史 Fantasy 分。
- **位置对位**：参考对手对相应位置的防守数据，控制为小幅修正；无法匹配时使用中性值。
- **盘口环境**：使用比赛总分线估计整体得分环境，限制影响范围。赔率数据按既定刷新节奏读取，缺失时不做调整。
- **伤病与替补机会**：可信的缺阵、存疑状态会降低出场预期；高风险状态可被排除。季前赛聚合伤病来源可信度较低，因此比官方报告更保守地使用，不把未确认消息等同于确定缺阵。队友缺阵时，满足条件的同位置替补可能得到有限的机会修正。
- **前五选人反馈**：公开的前五阵容与球员得分会汇总成历史偏好。高频入选且实际表现较好的球员可以得到轻量加分；这只是辅助信号，不会覆盖基础数据。
- **季前赛折扣**：季前赛轮换和上场时间更不稳定，预测统一应用轮换风险折扣。常规赛阶段不使用该季前赛折扣。
- **赛后校准**：已完成日期的预测和实际总分用于计算整体校准系数，并限制校准范围，避免少数异常结果大幅改变后续预测。

### 4. 组合五人阵容

阵容优化器在候选人中搜索五人组合，目标是最大化五人预计分数之和，并满足：

- 恰好五名不同球员；
- 前场 / 后场阵型为 2 前 3 后或 3 前 2 后；
- 总能量不超过 BAO5 的 150 上限；
- 被判定为高风险、不可选的球员不进入优化池。

因此，当前推荐是“符合约束的预期得分最高阵容”。在此目标下，如果增加能量能换来更高预测分，算法通常会继续使用能量；这并不表示游戏要求能量必须耗尽。未使用满额能量仍是合法阵容。

## 学习与迭代

模型的更新分为数据回填、观察反馈和参数校准：

1. 比赛结束后，优先读取 BAO5 已结算日榜回填实际得分；必要时用 NBA 官方 Box Score 作为备用来源。
2. 将每次预测、实际分数、排名和误差写入逐日历史，供页面回看。
3. 汇总公开的前五阵容和逐人得分，形成可审计的选人偏好统计。
4. 用已结算的实际/预测得分比更新总体校准系数，并限制变化幅度。
5. 自动任务持续刷新球员、赛程、伤病和赔率信息；临近锁定时按任务配置检查首发，并在合法窗口内更新提交阵容。

这套机制属于渐进式自我校准，不代表模型会自行训练新的机器学习模型或自动重写所有权重。权重变化仍由预设策略或用户设置决定；回填数据和运行日志用于检验这些策略是否值得调整。

## 对结果的理解

模型输出的是基于当前数据的估计，不是得分保证。季前赛上场时间、首发安排和临场伤病的不确定性尤其高。缺少来源的数据会被视为缺失或中性，而不会假装已知。开赛前 BAO5 会锁定当天阵容；锁定后模型即使出现新信息，也不能保证网站仍接受修改。
